# 🛍️ Mini Katalog App

A Flutter-based mobile catalog application built for educational purposes.

## Features
- 🏪 Multiple store support (TechMart, FashionHub, MegaStore)
- 🛒 Shopping cart
- 🧾 Order history
- 🔍 Product search & filtering
- 📦 Product detail screen

## Flutter Version
Flutter 3.x / Dart 3.x

## Getting Started
```bash
flutter pub get
flutter run
```
